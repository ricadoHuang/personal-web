# 黃暐哲｜個人作品集

以繁體中文呈現的個人品牌與作品集單頁網站，介紹黃暐哲的學習背景、研究經歷、專案成果、獲獎紀錄與資訊專業技能。

## 網站內容

- 個人介紹與學習亮點
- 畢業專題：VR 資安教育遊戲「零痕計畫・知識防線」
- 人機互動研究：假新聞的情緒喚醒與傳播行為分析
- 系統開發：企業員工打卡管理系統
- 跨領域產學合作：少爺丼飯數位轉型
- 人工智慧與大數據實驗室研究助理經歷
- 獲獎紀錄、專業技能與 TOEIC 成績

## 專案結構

```text
.
├── index.html        # 網站內容、樣式與導覽互動
├── assets/
│   └── profile.jpg   # 個人照片
└── README.md
```

## 如何瀏覽

此網站為純靜態頁面，無需安裝套件、建置或設定後端。

1. 下載或複製專案檔案。
2. 使用瀏覽器直接開啟 `index.html`。

也可以使用 Visual Studio Code 的 Live Server 等靜態網站伺服器預覽。

## 技術與特色

- HTML、CSS 與原生 JavaScript，無外部執行期依賴。
- 響應式版面，支援桌面與行動裝置。
- 以頁內導覽快速瀏覽各項經歷。
- 支援鍵盤焦點提示與減少動態效果偏好。

## 更新內容

- 編輯 `index.html` 可更新文字、版面、樣式與導覽互動。
- 替換 `assets/profile.jpg` 可更新個人照片；請保留此路徑與檔名，或同步修改圖片的 `src`。
